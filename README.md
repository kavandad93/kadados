# KadadOS

A from-scratch operating system project.

## Status

Early development.

The first milestone is a bootable x86_64 kernel with a text console and the Kadad shell.

## Shell

The planned prompt is:

```
kavan@Kadad--kavan /home/kavan/ >_
```

Initial commands:

- `nano`
- `ls`
- `dir`
- `mkdir`
- `rm`
- `rmdir`
- `cd`
